# 情绪板搜集助手

## 核心原则

- 完全依据本次项目简报生成关键词，不沿用任何荒野、自然摄影或既往项目关键词。
- 只继承多轮搜索、评分筛选、去重、统一命名和来源整理的方法。
- 优先使用当前环境可访问的浏览器检索 Pinterest；若用户的 Chrome 会话可用，可沿用其已有登录状态。按任务需要补充 Behance、Designspiration、BP&O、The Brand Identity、Brand New、It’s Nice That 等设计网站。
- 图片仅用于设计研究；保留完整来源，提醒商用或转载前确认授权。
- 不制作缩略图、拼图、总览或情绪板成品，除非用户明确要求。

## 执行流程

本 Skill 的关键是先把“想找什么”说清楚，再得到用户对搜索方案的确认，最后才开始检索。三个阶段必须分开；阶段一、二结束后等待用户回应，不得自动进入下一阶段。

### 第一阶段：确认要找的具体对象

收到搜集请求后，先用简短问题确认用户要找的东西、用途和边界。必须请用户提供参考示例，帮助判断其所说的风格、对象或效果具体指什么。示例可以是图片、链接、品牌/作品名称，或对照说明；若用户暂时没有，也请其描述“像什么/不像什么”。

优先确认这些会改变检索结果的信息：

- 具体要找什么对象或视觉元素，准备用于什么项目/场景？
- 有没有一至数个参考示例？示例中希望借鉴什么，哪些部分不需要？
- 需要覆盖哪些类别、气质、构图、人物/产品、色彩或设计机制？有什么禁用项？
- 希望搜集多少条/张，是否有指定平台、语言、时间范围或输出目录？

不要把问题清单机械地一次问完。用户已经给出答案的字段不重复追问；优先问会实质影响搜索方向的缺口。可从简报中提取项目与方向、核心气质、现有素材和缺口、类别、偏好/禁用项、数量和交付要求。

若用户给出的目标和示例仍无法判断具体要找的内容，继续澄清，不进入关键词规划。若需求已清楚但用户没有示例，先问其能否提供；用户明确表示没有时，可用其文字描述作为参考基准，并在下一阶段明示这个假设供确认。

### 第二阶段：提出搜索方案并征求确认

把已确认的需求整理成可执行方案，向用户展示并等待明确确认后再搜索。方案至少包含：

1. **检索目标与筛选边界**：用自己的话复述要找的内容、参考示例中要借鉴的点、类别范围和排除项。
2. **搜索关键词**：按类别列出拟用的中英文关键词/组合词，说明必要的同义词、行业词或视觉机制词。只从本次需求和示例推导，不沿用其他项目关键词。
3. **查找网站**：列出计划使用的平台及各自用途。优先考虑 Pinterest；按需求选用 Behance、Designspiration、BP&O、The Brand Identity、Brand New、It’s Nice That 等专业设计网站。说明若需用其他网站会加入方案供确认。
4. **搜集范围与交付**：建议数量、类别、筛选标准、下载/来源清单方式，以及目录（若已指定）。

询问用户是否确认这套关键词、网站和范围。收到确认前不得开始搜索、下载或浏览候选结果。用户提出修改时，更新方案并再次确认；用户明确授权直接执行时，可将该授权视为确认，但若方案中的关键内容尚未确定，仍先补齐。

### 第三阶段：检索、筛选与交付

确认后才开始检索。每个类别至少采用两种搜索视角：

1. 直接搜索用户给出的核心概念/对象。
2. 用英文设计术语、相邻行业或成熟品牌案例扩展。

先浏览整体结果，再收窄至强候选。对结果过泛的关键词增加具体限定；对结果过窄的关键词替换同义词。避免为了凑数保留普通模板、无设计关系的摄影或同质图片。严格依据用户确认的目标和筛选边界执行；若检索中发现原方案明显无法得到相关结果，暂停并向用户说明原因、提出调整后的关键词/网站，待确认后继续。

### 筛选评分

每张候选按 0—2 分评估：

| 维度 | 判断标准 |
|---|---|
| 简报相关性 | 是否回应本轮目标和缺口 |
| 品牌设计价值 | 是否能说明 Logo、色彩、字体、图形、版式、人物或产品关系 |
| 视觉质量 | 构图、细节、留白和完成度是否成熟 |
| 气质匹配 | 是否符合目标气质且避开禁用风格 |
| 可延展性 | 是否能转化为品牌系统或具体设计规则 |
| 独特性 | 是否与已选图片及已有素材明显不同 |
| 来源完整度 | 是否可记录标题、作者和原始页面 |

优先保留总分 10 分及以上的图片。若来源信息不足但视觉价值突出，可保留并在清单中明确标注“页面未显示”。

### 5. 下载与整理

- 只下载最终精选图片，不下载头像、平台图标、广告位或无关配图。
- 按用户指定目录保存；未指定时创建项目名与方向名组合的文件夹。
- 按类别建立子文件夹。
- 使用 `序号_内容描述.扩展名` 统一命名，如 `01_人物观点编辑排版.jpg`。
- 同一种构图或视觉机制通常不超过两张。
- 不擅自创建 ZIP、总览图或缩略图。

### 6. 来源清单

在素材目录中创建 `来源与筛选说明.md`：

| 文件 | 类别 | 保留理由 | 标题 | 作者/发布者 | 原始链接 |
|---|---|---|---|---|---|

要求：

- 原始链接优先使用作品详情页或 Pinterest Pin 页面，而不是搜索结果页。
- 标题和作者以页面显示为准，不推测未知信息。
- 保留理由必须指出具体可借鉴之处，避免“好看”“符合气质”等空泛描述。
- 用户只要求下载时，仍保留简洁来源清单，除非用户明确说不要。

## 浏览器使用

- 使用当前环境提供的浏览器工具；若可访问用户现有 Chrome 会话，优先使用该会话。
- 在搜索开始前阅读并遵守所用浏览器工具的说明。
- 优先通过页面可见结果和页面资源能力下载，不直接拼接图片 CDN 地址。
- 搜索结束后释放浏览器控制；保留用户原有标签页状态。

## 交付检查

- 图片数量符合要求。
- 类别覆盖完整。
- 没有明显重复、禁用风格或普通模板。
- 文件名统一且文件非空。
- 每张图均有类别、保留理由、标题、作者和原始链接。
- 未生成用户未要求的缩略图、总览图或情绪板成品。
